# La Torre del Ahorcado
El proyecto torre del ahorcado consiste en una versión modificada y evolutiva
del clásico juego del ahorcado, diseñada baja un estructura de dificultad
progresiva en formato de torre. El sistema cuenta con un total de 5 niveles
que el jugador debe superar. Además, incorpora un menú interactivo dinámico
que permite al usuario personalizar su experiencia seleccionando entre 5
temáticas diferentes en español e ingles.
